> 사용자가 실제로 쓰던 매매법을 SOXLUSDT 1분봉 165,646봉(2026-05-15 ~ 09-07, 115일)에
> 그대로 코드로 옮겨 964개 조합으로 돌린 결과다. `docs/08` 과 같은 방법론을 쓴다.

## 0. 한 줄 결론

**방향 예측력은 실재한다. 그런데 그 우위는 "오래 들고 있을 때만" 나온다.
몇 분~몇 시간으로 자르면 우위가 전부 사라진다.**

## 1. 무엇을 어떻게 테스트했나

사용자 설명을 그대로 파라미터로 옮겼다.

| 축 | 값 |
|---|---|
| 타임프레임 | 1분봉, 5분봉 (+ 별도로 15/30/60분) |
| 정배열 조건 | 없음 / 9>20 / 9>20>99 / 9>20>99>200 |
| 진입 | EMA9 눌림, EMA20 눌림, EMA99 눌림, 9-20 크로스 |
| 손절 | EMA20, EMA99, ATR×1.5, ATR×2.5, 스윙 |
| 익절 | EMA9 이탈, EMA20 이탈, 2R, 3R |

**규칙은 기존 시뮬레이터와 동일하게 보수적으로 맞췄다.**
신호는 종가로 판단하고 진입은 **다음 봉 시가**, 같은 봉에서 손절·익절이 둘 다 닿으면 **손절**,
왕복 비용 0.14%(수수료 0.08 + 슬리피지 0.06)를 R 로 환산해 차감.

## 2. 1차 스윕 — 640개 조합

```
양수 26개 / 640개 (4%)
최악 조합 −1.14R   (1분봉 + EMA20 손절)
```

4% 는 동전 던지기(50%)보다 훨씬 낮다. 이유는 단순하다.
**손절이 좁으면 손절폭 대비 비용 비율이 커진다.**

```
비용(R) = 왕복비용% ÷ 손절폭%
        = 0.14 ÷ 0.30  = 0.47R   ← 1분봉 EMA20 손절
        = 0.14 ÷ 1.20  = 0.12R   ← 5분봉 EMA99 손절
```

1분봉 EMA20 손절은 **이기든 지든 매매당 0.47R 을 먼저 낸다.** 승률 40% 에 3R 익절이어도
0.4×3 − 0.6×1 − 0.47 = **−0.27R**. 방향이 맞아도 구조적으로 못 이긴다.

## 4. 결정적 실험 ① — 문제는 방향인가 비용인가

기대값이 비용선과 거의 같았다. 두 해석이 가능하다.

- **(A)** 방향 예측력 0 → 비용을 없애도 0 근처
- **(B)** 방향 예측력 있음 → 비용이 그걸 다 먹음 → 비용 낮추면 양수

동일 프로토콜(IS 선택 → OOS 채점)로 비용만 바꿔 돌렸다.

| 왕복비용 | 의미 | IS 양수 | OOS 양수 | **OOS 기대값 평균** |
|---|---|---|---|---|
| 0.14% | 현재 시장가 | 41/640 | 2/10 | **−0.065R** |
| 0.08% | 지정가 체결 | 81/640 | 2/10 | **−0.005R** |
| 0.04% | 메이커 수수료만 | 168/640 | 3/10 | **+0.064R** |
| 0.00% | 이론값 | 546/640 | 5/10 | **+0.168R** |

**답은 (B).** 총수익(gross)은 +0.17R 로 양수인데 비용 0.12~0.28R 이 그걸 먹는다.
손익분기 비용은 대략 **왕복 0.05~0.08%**.

## 5. 결정적 실험 ② — 방향 뒤집기 대조군

같은 자리에서 **방향만 반대로** 잡는다. 방향 예측력이 없으면 뒤집어도 성적이 같아야 한다.

| 비용 | 원본 IS | 원본 OOS | 뒤집기 IS | 뒤집기 OOS |
|---|---|---|---|---|
| 0.00% | **+0.337** | **+0.199** | −0.047 | +0.034 |
| 0.14% | **+0.113** | −0.070 | −0.219 | −0.209 |

**모든 칸에서 원본이 뒤집기보다 0.14~0.38R 좋다.**
이 프로젝트에서 방향 대조군을 통과한 전략은 이게 처음이다.
(참고: S1 VWAP 되돌림은 뒤집기가 **더 좋았다** — 즉 우위가 없었다. `docs/08`)

## 6. 결정적 실험 ③ — 다중검정 통제

640개 중 6개가 좋아 보이는 건 640번 뽑았기 때문일 수 있다.
그래서 **640개 전부**를 6구간으로 쪼개 '양수 구간 수' 분포를 봤다.

```
양수 0/6 : 472개 (73.8%)
양수 1/6 :  87개 (13.6%)
양수 2/6 :  38개 ( 5.9%)
양수 3/6 :  30개 ( 4.7%)
양수 4/6 :   7개 ( 1.1%)
양수 5/6 :   6개 ( 0.9%)   ←
양수 6/6 :   0개 ( 0.0%)
```

5구간 이상 양수는 **640개 중 6개(0.9%)** 뿐이고, 그 6개가 한 곳에 뭉쳐 있다.

| | 5/6 통과 6개의 공통점 |
|---|---|
| 타임프레임 | **전부 5분봉** (1분봉 0개) |
| 정배열 | **전부 align 3 이상** (9>20>99), 6개 중 5개가 align 4 (200 까지) |
| 진입 | **전부 눌림** (크로스 진입 0개) |
| 손절 | **전부 넓은 손절** — EMA99 / ATR×2.5 / 스윙. **EMA20 손절은 0개** |
| 익절 | **전부 R배수** (2R·3R). EMA 이탈 청산 0개 |

우연이면 640칸에 흩어져야 한다. 한 구석에 뭉친 건 **구조가 있다**는 뜻이다.

## 7. ⚠️ 치명적 단서 — 우위는 "오래 들고 있을 때만" 나온다

평균 보유가 **1,240분 = 20.7시간**이다. 데이트레이딩이 아니다.
그래서 '몇 봉 지나면 무조건 시장가 청산' 을 걸어봤다.

| 조합 | 무제한 | 6.5h | 4h | 2h | 1h |
|---|---|---|---|---|---|
| A | **+0.25** | −0.18 | −0.14 | −0.13 | −0.15 |
| B | **+0.24** | −0.26 | −0.24 | −0.21 | −0.21 |
| C | **+0.15** | +0.01 | −0.06 | −0.08 | −0.12 |
| D | **+0.11** | −0.01 | −0.10 | −0.10 | −0.11 |

**보유를 자르는 순간 우위가 전부 사라진다.**
즉 이 전략은 **스윙**이지 데이트레이딩이 아니다.

### 그런데 오버나이트에는 별도의 위험이 있다

본주가 닫힌 CLOSED 구간 동안 perp 은 혼자 움직인다. 77거래일 측정:

```
CLOSED 구간 변동  중앙값(절대) 5.749%   범위 −21.06% ~ +16.03%
```

**10배 레버리지에서 손절선 1.2% 는 갭으로 뛰어넘어진다.** 손절이 작동하지 않는다.
그리고 그 변동이 개장 후 방향을 예측하지도 못한다 — 상관계수 15분 +0.115,
30분 −0.089, 60분 −0.064, 120분 −0.003. **전부 0.** 갭 페이드도 안 된다.

## 8. 그래서 실제로 뭘 해야 하나

### 확정된 것
1. 사용자의 EMA 정배열 눌림 방식에는 **방향 정보가 있다** (대조군 통과, 다중검정 통과)
2. 그 우위는 **5분봉 · 정배열 3선 이상 · 눌림 진입 · 넓은 손절 · R배수 익절** 조합에만 있다
3. **EMA20 손절은 전멸이다** — 비용/손절폭 비율이 우위를 넘는다
4. 우위 크기(gross +0.17R)가 비용(0.12~0.28R)과 같은 자릿수 → **비용이 성패를 가른다**
5. 우위는 **수 시간~수일 보유**에서만 실현된다. 1시간 이하로 자르면 없다
