## 4. 종합 전략 — "그래도 SOXL 을 한다면" (페이퍼 전용)

측정이 지지하는 규칙만 모은 것. 이름은 **SOXL 정배열 눌림 · 본장 밖** 으로 부른다.

```
타임프레임  5분봉 (바이낸스 SOXLUSDT perp)
큰 추세     종가 > EMA200 (롱) / < EMA200 (숏)
정배열      EMA9 > EMA20, 둘 다 상승 중 (숏은 반대)
눌림        직전 3봉 안에 저가가 EMA20 에 닿음
진입        종가가 EMA9 위로 복귀한 봉의 다음 봉 시가 (시장가 또는 그 가격 지정가)
손절        EMA99 × 0.998 (평균 1.5%)           ← 스윙 손절(1.2%)은 털린다
익절        3R (손절 거리 × 3)                   ← 2R 은 마이너스
시간대      본장(09:30~16:00 ET) 신호는 버린다   ← 본장 안 −0.33R
크기        시드 10% × 10배 = 노셔널 1배. 매매당 위험 ≈ 시드의 1.5%
금지        고영향 이벤트 ±30분, 일일 −3R 도달 후 (기존 가드)
```

**실측(115일)**: 316건, 승률 36%, 기대 +0.144R, 뒤집기 −0.322R, IS +0.096 / OOS +0.218, 시드 4.33x, MDD 20%, 평균 보유 5시간, 하루 2.7건.
OOS 만으로 한 달 기대 ≈ 2.7건/일 × 21일 × 0.218R × 1.3% ≈ **+16%/월** (표본 46일, t≈1.3 — 아직 우연과 구분 안 됨).

엔진은 관찰(국면·신호 표시)만 하도록 두고 주문은 끄는 게 맞다 (`TH_SIGNAL_SYMBOLS` 에서 빼면 된다).

### 자동 엔진이 실제로 하는 매매와 백테스트의 차이

| 항목 | 백테스트 | 엔진 (`th.execution.signals`) |
|---|---|---|
| 신호 | 봉 종가 | 봉 마감 +6초, 바이낸스 공개 5분봉으로 같은 계산 |
| 진입 | 다음 봉 시가 | 시장가 (마감 직후 호가 ≈ 다음 봉 시가) |
| 손절 | 신호 봉 종가 −3% | **현재가** −2.95% (가드 상한 3% 안쪽) |
| 청산 | 종가가 20선 반대로 → 다음 봉 시가 | 같은 판정 → 시장가 |
| 시간대 | Y1~Y5 로 선택 | SOXL 은 세션 게이트(docs/05)가 **본주 정지 시간(20:00~04:00 ET·주말)을 막는다** → 실제로는 프리·애프터·본장만. BTC·ETH 는 게이트 없음 |
| 동시 포지션 | 종목당 1개 | 종목당 1개 + 전체 `TH_MAX_OPEN_BRACKETS` (기본 1) |
| 크기 | 시드 10% × 10배 | `risk_pct = 손절폭 × TH_SIGNAL_NOTIONAL_X` → 노셔널 = 시드 × 1.0 |

세션 게이트 때문에 SOXL 엔진의 실제 기회는 **Y5(프리·애프터) + 본장** 이다. 본장 신호가 마이너스였던 것(A7 −0.33R, Y 계열도 본장 밖이 낫다)을
생각하면 `TH_SIGNAL_MODE` 와 별개로 **본장 중에는 엔진을 끄는 것**이 백테스트에 가장 가깝다. 그 스위치는 백테스트 페이지 상단에 있다.
