# 11 — EMA99 터치 전략 최종 판정

> 결론: **우위 없음. 이 노선은 종료한다.**
> SOXLUSDT 4개월에서 좋아 보였던 것은 34종목을 다 돌렸을 때 우연히 하나가
> 그렇게 보일 확률과 정확히 일치한다.

## 1. 최종 수치

38종목 · 7,576,331봉 · 체결 15,458건 · 왕복비용 0.11%(실측)

```
기대값        −0.147R
비용          −0.155R  (0.11% ÷ 평균 손절폭 0.71%)
총수익(gross) +0.008R  ← 진입 자체의 가치가 사실상 0
방향 대조군 차이 +0.030R
```

승률도 무작위 진입의 이론값과 소수점까지 같았다.

```
손절 0.71% / 익절 1.5%  →  이론 32%   실측 32%
손절 0.72% / 익절 2.0%  →  이론 26%   실측 26%
손절 1.10% / 익절 1.5%  →  이론 42%   실측 41%
```

**진입 시점이 무작위와 구별되지 않는다.**

## 2. SOXL 은 왜 좋아 보였나 — 다중검정

가장 좋았던 조합(SOXL · ER(50)≥0.20)을 통계적으로 검정했다.

```
체결 46건 · 기대값 +0.396R · 표준편차 1.469R
표준오차 0.217R · t = 1.83 · 단측 p = 0.034
기대값 95% 신뢰구간  −0.029 ~ +0.820R   ← 0 을 포함한다
```

p = 0.034 는 한 종목만 봤다면 유의해 보인다. 그런데 우리는 **34종목을 다 돌렸다.**

```
우연히 이만큼 좋아 보이는 종목의 기대 개수 = 34 × 0.034 = 1.15개
실제로 관측된 개수                          = 1개 (SOXL)
```

**우연이 예측한 값과 정확히 같다.** 신뢰구간도 0을 포함한다.
SOXL 은 특별한 종목이 아니라, 34번 뽑기에서 나온 당첨 하나였다.

## 3. 검증 과정에서 잡은 오류 3건

이 판정에 도달하기까지 우리 쪽 버그를 세 번 고쳤다. 기록해둔다.

### 3-1. 접근 방향 미구분 (승률 97%, 누적 +15,000%)
EMA99 **아래**에 있는 봉을 "저가가 EMA99 에 닿았다"고 롱으로 잡았고,
손절을 EMA99 아래에 두니 **손절가가 진입가보다 위**에 놓였다. 손절이 이익으로 계산됐다.
→ 접근 방향으로 지지/저항을 구분하도록 재작성. 불변식 검사 추가:
   **손절로 끝난 매매는 절대 이길 수 없다 (승리 ≤ 익절 + 시간청산).**

### 3-2. 대조군 오염 (차이 +0.24 → 실제 +0.03)
원본과 뒤집기가 청산 시점이 갈리면서 **서로 다른 매매**를 하고 있었고,
뒤집으면 손절폭까지 바뀌었다(0.76% → 0.35%). 비용이 상쇄되지 않았다.
→ 손절 거리는 원래 신호 방향으로 계산하고 대조군은 방향만 뒤집도록 수정.
   모든 신호를 독립 평가하는 모드 추가. 검사 항목 추가:
   **원본과 뒤집기의 신호 수·평균 손절폭이 정확히 일치해야 한다.**

### 3-3. 비용 과대평가 (0.14% → 0.11%)
슬리피지를 0.06% 로 가정했는데 실측 스프레드는 **0.0079%** 였다(4,413건, 중앙값 0.79bps).
→ 실측 기반으로 교체. 이건 결론을 뒤집지 못했지만, 한때 뒤집을 뻔했다.

### 레버리지 ETF 가설 — 사전에 기준을 정하고 검정했다

기존 4종목(SOXL/SOXS/TQQQ/SQQQ)이 나머지 30종목과 뚜렷이 달라 보였다.
근거 있는 메커니즘도 있었다 — 3배 ETF 는 매일 배율을 다시 맞춰야 해서
오르면 사고 내리면 파는 강제 흐름이 생긴다.

한 번도 쓰지 않은 레버리지 ETF 로 검증했다(TZA, UVXY).

(참고: 방향 대조군 차이만은 신규 레버리지에서 +0.26~0.35 로 일반(+0.02~0.04)보다

## 7. 다음 방향

방향 예측(디렉셔널 TA)으로는 이 종목·이 시간대에서 세 번 연속 우위가 없었다.
그러면 **방향을 안 맞혀도 되는 구조**로 옮기는 게 맞다. 후보 둘:

### (A) 3배 ETF 짝 공매도 — 변동성 감쇠 + 펀딩
SOXL(+3배)과 SOXS(−3배)를 **동시에 공매도**하면 방향 노출이 상쇄된다.
3배 ETF 는 변동성이 클수록 양쪽 다 가치가 깎이므로 공매도한 쪽이 그걸 가져간다.
이건 예측이 아니라 리밸런싱에서 나오는 **수학적 성질**이다.
여기에 펀딩(실측 연 19%)이 더해진다.
→ 측정 도구: `scripts/pair_decay.py`
→ 위험: 한쪽으로 강한 추세가 나면 그쪽 공매도가 크게 밀린다. 낙폭 실측이 먼저다.

### (B) 다일 추세추종 (문헌 근거 있음)
암호화폐에서 비용 차감 후에도 살아남은 것으로 보고된 유일한 계열.
룩백 28일 / 보유 5일에서 Sharpe 1.51 (15bp 비용 차감 후).
BTCUSDT 는 2020-01 부터 **81개월** 1분봉이 무료로 있다 — 표본 문제가 없다.
→ 우리 1차 EMA 실험에서 "보유를 자르면 우위가 사라진다"고 나온 것과 방향이 같다.
