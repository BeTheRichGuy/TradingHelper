## 0. 한 줄 결론

**전략보다 레버리지가 결과를 정한다.**
우리가 측정한 어떤 신호도 10배에서 살아남지 못했고, 같은 신호가 2~3배에서는 살아남았다.
가장 안정적인 방법은 "더 좋은 신호"가 아니라 **분산 + 낮은 레버리지 + 차단 규칙**이다.

## 2. 왜 전부 10배에서 죽었나 — 한 개의 공식

측정한 모든 결과가 이 한 줄로 설명된다.

```
실제 복리 성장률 ≈ L·μ − L²σ²/2
                   ↑선형 이익   ↑변동성 손실 (제곱으로 커진다)
```

#8 신호(일평균 μ=+0.179%, 일변동성 σ=2.46%)를 레버리지만 바꿔 돌린 실측:

| 레버리지 | 이론(선형) | **실제** | MDD |
|---|---|---|---|
| 1배 | 1.32x | 1.26x | 21% |
| **3배** | 2.28x | **1.52x ← 최고** | 53% |
| 5배 | 3.94x | 1.28x | 75% |
| 10배 | 15.3x | **0.15x** | 98% |

```
켈리 최적 레버리지  = μ/σ² = 2.95배
10배에서 변동성 손실 = 하루 3.03%  (엣지 0.179%의 17배)
```

**엣지가 있어도 10배는 그것을 음수로 바꾼다.** 이건 신호를 더 좋게 만들어서 해결되는
문제가 아니다. 적중률 65%(비현실적)여도 최적 레버리지는 5.5배, 월 2배에 필요한 적중률은
어떤 레버리지에서도 75% 이상이다.

### 형이 실제로 해온 방식은 이미 그 근처에 있다

> "시드의 10~20%를 10배로" = **계좌 기준 1~2배.**

거래소 설정이 10배일 뿐 계좌 노출은 1~2배였다. 그래서 지금까지 안 터진 것이다.
위험은 레버리지 숫자가 아니라 **한 종목에 집중**하는 데 있다 — SOXL 은 3배 ETF 라
10배 = 지수 30배이고, 본주 휴장 중 단독 변동 중앙값이 5.75% 다.
계좌 노출 1~2배를 유지하되 **한 종목이 아니라 여러 종목에 나누는 것**, 그게 형 방식의 개선판이다.

## 3. 비용이 두 번째 결정 변수

| 항목 | 실측 |
|---|---|
| 시장가 왕복 | **0.11%** (테이커 0.10 + 스프레드 0.008 + 펀딩 0.003) |
| 지정가 왕복 | **0.05%** |
| SOXL 펀딩 | 0.0172%/8h ≈ **연 19%** (롱이 낸다) |

```
비용(R) = 왕복비용 ÷ 손절폭
  손절 0.3% 시장가 → 0.37R   매매마다 먼저 낸다 → 못 이긴다
  손절 1.2% 지정가 → 0.04R   이기면 남는다
```

docs/09 에서 비용을 0.14 → 0.08 로 낮추자 OOS 기대값이 −0.065 → −0.005R,
0.04 에서 +0.064R 이 됐다. **손절 0.5% 미만 + 시장가 조합은 구조적으로 금지**해야 한다.

## 4. 제안 — "가장 안정적인" 레버리지 운용

측정이 뒷받침하는 것만 넣었다. 우선순위 순.

### 4-1. 규칙 (전략과 무관하게 항상)

| 규칙 | 값 | 근거 |
|---|---|---|
| 계좌 총 노출 | **≤ 3배** (평상시 2배) | 켈리 2.95, 레버리지 곡선 최고점 |
| 한 종목 노출 | **≤ 계좌의 1배** | 10분할 구조가 청산 0회를 만든 이유 |
| 손절폭 | **≥ 0.5%**, 진입·청산 지정가 우선 | 비용/R |
| 일일 손실 한도 | −3R (이미 구현) | 실행 가드 |
| 이벤트 차단 | 고영향 이벤트 ±30분 신규 진입 금지 | 세션 게이트가 유일하게 값을 함 |
| 본주 휴장 보유 | 3배 ETF(SOXL/SOXS/TQQQ/SQQQ)는 **휴장 전 청산 또는 사이즈 절반** | 휴장 중 5.75% 단독 변동, 손절 무력화 |

### 4-2. 수익 구조 — 세 층

```
① 코어   36종목 분산 바스켓, 계좌 1~2배            ← 베타. 선택 안 함. 샤프 ~1 (상승장 표본)
② 오버레이 docs/09 정배열 눌림 스윙, 종목당 ≤1배     ← 유일한 방향 우위. 넓은 손절·R배수 익절
③ 실험   #8 일간 상위20% 신호, 페이퍼 전용          ← 구조 합격, 신호는 전방 검증 전까지 실전 금지
```

①은 "예측을 안 하는" 층이다. 36종목 상관 0.07 → 유효 독립 10종목이라 분산이 실제로 먹힌다.
다만 표본이 상승장 5.5개월뿐이라 **하락장 한 번이면 뒤집힐 수 있는 잠정 결론**이다.
②는 표본 115일·SOXL 단독이었으므로 다종목(`scripts/ema_multi.py`)에서 24/34 통과해야 실전이다.

### 4-3. 목표 재설정

```
월 2배      → 적중률 75% 필요. 도달 불가.
월 5%       → 연 1.8배.  분산 2배 바스켓 실측 범위 안.
월 8%       → 연 2.5배.  ②가 다종목에서 검증되면 가능 범위.
```

목표를 "수익률"이 아니라 **"최대낙폭 15% 안에서 낼 수 있는 최대"**로 바꾸는 게 맞다.
낙폭이 정해지면 레버리지가 정해지고, 레버리지가 정해지면 수익률은 결과로 나온다.

## 6. 전체 계획에 대한 제안 (Fable)

### 지금 방향에서 바꿨으면 하는 것 세 가지

**① "예측 앱"에서 "규율 앱"으로 포지셔닝을 명시적으로 옮기자.**
docs/13 §6 과 같은 결론인데, 근거가 더 쌓였다. 8개 아이디어 중 방향 우위는 1개(조건부).
반면 안전장치·차단·비용 절감·사후 분석은 전부 측정 가능하고 이미 대부분 구현돼 있다.
"승률 몇 %" 대신 **"당신의 최대낙폭을 15% 안에 잡아드립니다"**가 이 데이터가 지지하는 약속이다.

**② 백테스트는 이 데이터에서 끝났다. 전방(forward) 기록으로 넘어가자.**
주식 perp 역사가 4~7개월이고 전부 한 국면이다. 여기서 뭘 더 돌려도 표본은 안 는다.
대신 **매일 장 시작 전 시그널·뉴스·순위를 기록하고 결과를 자동 채점**하는 기록기를 만들면
60거래일 뒤에는 지금까지 어떤 백테스트보다 깨끗한 표본이 생긴다 (룩어헤드가 원천 불가능).
페이퍼 클라이언트·저널·가드가 이미 있으니 붙이는 데 1~2일이다.

**③ LLM 은 방향이 아니라 차단·분류·사후분석에만 쓰자 — 그리고 그것부터 검증하자.**
docs/06 D모듈 + `th gate-value` 조합. 유일하게 성공한 필터(세션 게이트)가 시간·이벤트 축이었고
LLM 의 강점이 정확히 거기다. 뉴스 백테스트는 모델이 결과를 이미 알고 있어 무의미하므로
이것도 ②의 전방 기록 위에서만 검증한다.

### 순서

| 순서 | 작업 | 기간 | 완료 기준 |
|---|---|---|---|
| 1 | 이번 수정 적용 → 데스크탑 `pytest` 전체 통과 → `th paper` 재점검 | 0.5일 | 테스트 0 실패, 마이그레이션 004 적용 |

| 4 | **시그널 기록기** (일간 순위 + 뉴스 스냅샷 + 자동 채점) | 1~2일 | 매일 09:20 ET 자동 기록, 결과 DB |
