## 지금 위치

**Phase 0~4 완료 → Phase 5(웹 대시보드) 착수 대기.**

Phase 4(백테스트)는 **불합격**이다 — 셋업에 방향성 우위가 없는 것으로 측정됐다.
로드맵에 처음부터 적어둔 대로 **신호 카드를 빼고** 청산 회피·손절 누락 경고·세션
게이트만으로 Phase 5 를 간다. 판정 근거와 재현 방법은 [08-전략-검증-결과](08-전략-검증-결과.md).

세부 진행 상황과 계획에서 달라진 점은 [04-개발-로드맵](04-개발-로드맵.md)에 있다.
아침에 처음 보신다면 프로젝트 루트의 [PHASE5-준비.md](../PHASE5-준비.md) 부터.

## 문서를 고치는 규칙

- 결정이 바뀌면 **코드보다 문서를 먼저** 고친다. 나중에 "왜 이렇게 했지"를 되짚을 수 있어야 한다.
- 계획과 다르게 구현했다면 그 사실을 문서에 남긴다. 조용히 어긋난 문서가 가장 위험하다.
- 이 문서들은 claude.ai 프로젝트에도 같은 내용이 올라가 있다. 한쪽만 고치면 갈라지므로, 대화 중에 고친 내용은 양쪽에 반영한다.
