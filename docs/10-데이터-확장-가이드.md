# 데이터 확장 가이드 (Phase 4.5)

> 형이 실제로 쓰던 **5분봉 EMA99 지지/이탈** 기준이 640개 조합 중 다중검정을 통과한
> 조합들과 정확히 일치했다. 이제 표본을 늘려서 그게 진짜인지 확인한다.

---

## 0. 먼저 알아야 할 사실 — SOXLUSDT 는 더 못 늘린다

바이낸스 공식 아카이브를 직접 확인했다.

```
data/futures/um/monthly/klines/SOXLUSDT/1m/
  SOXLUSDT-1m-2026-05.zip   ← 여기가 처음
  SOXLUSDT-1m-2026-06.zip
  SOXLUSDT-1m-2026-07.zip
  SOXLUSDT-1m-2026-08.zip
일별 파일 최초: 2026-05-15
```

**SOXLUSDT 는 2026년 5월 15일에 상장했다. 그 전 데이터는 세상에 없다.**
형이 이미 가진 165,646봉이 존재하는 전부다. 1년치를 모을 방법이 없다.

그래서 방향을 바꾼다. **기간을 늘리는 대신 종목을 늘린다.**

기간을 늘리면 "그 종목의 그 시절"을 더 보는 것뿐이다.
종목을 늘리면 **"이 규칙이 SOXL 만의 우연이 아닌가"** 를 직접 묻게 된다.
지금 우리한테 필요한 건 후자다.

## 1. 세 갈래 — 뭘 받을 수 있나

### 갈래 A. 형제 주식 perp (무료 · 즉시 · 강력) ⭐ 먼저 이거

바이낸스에 미국 주식·ETF perp 이 **35개 이상** 있다. 전부 SOXL 과 같은 시기에
상장해서 기간은 똑같이 ~4개월이지만, **서로 다른 종목**이다.

| 묶음 | 종목 | 왜 |
|---|---|---|
| 반도체 | SOXS, SMH, NVDA, AMD, INTC, SMCI | **SOXS 는 SOXL 의 정반대(-3x)** — 공매도 쪽 자연 대조군 |
| 지수 ETF | SPY, SPX, QQQ, TQQQ, SQQQ | 레버리지 ETF 구조가 같은지 |
| 대형 기술주 | AAPL, MSFT, GOOGL, AMZN, META, TSLA, NFLX | 3배 레버리지 없는 일반 주식에서도 되나 |
| 기타 | MSTR, COIN, GME, PLTR, GLD, GDX | 변동성 성격이 다른 것들 |

**35종목 × 165,646봉 ≈ 580만 봉.** SOXL 하나의 35배다.
그리고 매 종목마다 방향 뒤집기 대조군을 같이 돌린다.
**35종목 중 25종목 이상에서 원본이 대조군을 이기면, 그건 우연이 아니다.**

### 갈래 B. 크립토 장기 이력 (무료 · 표본 거대)

BTCUSDT 는 **2020년 1월부터 81개월치** 1분봉이 다 있다. ETH, SOL 등도 마찬가지다.
주식이 아니라서 성격은 다르지만, 묻는 질문이 다르다 —

> "EMA99 정배열 눌림"이 **주식 perp 만의 현상**인가,
> 아니면 추세가 있는 시장이면 어디서든 나오는 **일반적 구조**인가?

일반적 구조라면 훨씬 믿을 만하다. 그리고 5년 넘는 구간에는
상승장·하락장·횡보장이 다 들어 있어서 **국면별로 언제 통하고 언제 깨지는지**를 볼 수 있다.
이건 4개월짜리 SOXL 로는 절대 못 보는 것이다.

### 갈래 C. SOXL 본주 1분봉 (유료 · 나중에)

perp 이 아니라 **진짜 SOXL 주식** 데이터는 2010년부터 있다. 다만 무료가 아니다.

| 방식 | 서비스 | 성격 |
|---|---|---|
| 1회 구매 | [FirstRate Data](https://firstratedata.com/) — 25년치 분봉 판매 | 한 번 사면 끝. 개인 개발자한테 제일 깔끔 |
| 월 구독 | [Polygon.io](https://tradingtoolshub.com/review/polygon-io/) | 실시간까지 필요해지면 그때 |
| 종량제 | [Databento](https://databento.com/stocks) — $125 무료 크레딧 제공 | 필요한 만큼만. 무료 크레딧으로 SOXL 몇 년치는 받아볼 만함 |
| 무료 | yfinance | **1분봉은 최근 7일뿐.** 우리 용도엔 못 씀 |

⚠️ **단, 본주는 perp 과 다른 물건이다.** 펀딩비가 없고, 24시간 안 돌고,
휴장 중 단독 변동(중앙값 5.7%)이 없다. 그래서 **본주 데이터는 "EMA99 눌림이라는
구조 자체가 이 종목에 몇 년째 존재했나"를 확인하는 용도**지, perp 백테스트의
대체품이 아니다. 갈래 A·B 를 먼저 하고, 결과가 좋으면 그때 사자.

## 2. 실행 — 순서대로 따라 하면 된다

### 준비: 명령 프롬프트 열기

`Win + R` → `powershell` 입력 → Enter. 그다음:

```powershell
cd C:\Users\nemo0\source\trading-helper
```

> 💡 파이썬 가상환경(`.venv`)을 쓰고 있었다면 먼저 켜자:
> `.\.venv\Scripts\Activate.ps1`
> 프롬프트 앞에 `(.venv)` 가 붙으면 켜진 것. 안 켜도 이 스크립트는 돌아간다
> (표준 라이브러리만 쓴다. pip 설치 필요 없음).

---

### 1단계 — 받을 수 있는 종목 확인

```powershell
python scripts\fetch_vision.py --list
```

**예상 출력** (심볼 500개 넘게 쭉 나온다):

```
바이낸스 아카이브에 있는 심볼 목록을 가져오는 중...
총 573개

  1000BONKUSDT  1000FLOKIUSDT ...
  ...
  SOLUSDT       SOXLUSDT      SOXSUSDT      SPXUSDT      SPYUSDT   ...
```

여기서 `SOXLUSDT`, `SOXSUSDT` 가 보이면 정상이다.
혹시 내가 프리셋에 넣은 종목 중 목록에 없는 게 있으면 그건 그냥 건너뛰어진다 (에러 아님).

---

### 2단계 — 주식·ETF perp 전부 받기 ⭐

```powershell
python scripts\fetch_vision.py --symbols stocks
```

**예상 출력:**

```
종목 37개 · 저장 위치 C:\Users\nemo0\source\trading-helper\dataset\vision
(같은 파일을 두 번 받지 않도록 zip 을 dataset/.vision_cache 에 보관한다)

  SOXLUSDT     ✅ 165,646봉  2026-05-15 ~ 2026-09-07
  SOXSUSDT     ✅ 164,880봉  2026-05-15 ~ 2026-09-07
  SMHUSDT      ✅ 158,201봉  2026-05-20 ~ 2026-09-07
  ...
  UNHUSDT      ❌ 월별 파일 없음 — 심볼 이름이 맞는지 확인 (--list)

완료 — 종목 34/37 · 총 5,412,880봉 · 284초
```

- ⏱ **5~15분**
- 💾 **약 500MB** (CSV 400MB + zip 캐시 100MB)
- ❌ 몇 개 실패하는 건 정상이다. 그 종목이 아직 상장 안 됐거나 이름이 다른 것뿐.

> 중간에 끊겼으면 **그냥 같은 명령을 다시 치면 된다.** 받은 파일은 캐시에서 읽는다.

---

### 3단계 — 다종목 백테스트 ⭐ 여기가 핵심

```powershell
python scripts\ema_multi.py
```

**예상 출력:**

```
왕복비용 0.14% · 종목 34개

================================================================================================
A  EMA9눌림/EMA99손절/3R
  종목                   봉     체결     승률        95%CI      기대값      누적R      뒤집기      차이
  AAPLUSDT       162,400     98    33%       24~43%   +0.180    +17.6   +0.020  +0.160
  AMDUSDT        164,100    141    36%       28~44%   +0.221    +31.2   -0.045  +0.266
  SOXLUSDT       165,646    125    35%       27~44%   +0.254    +31.8   +0.118  +0.136
  SOXSUSDT       164,880    132    31%       24~40%   +0.090    +11.9   -0.130  +0.220
  ...
  ────────────────────────────────────────────────────────────────────────────────────
  합계                      3,847    34%       32~35%   +0.19x  +73x.x   +0.0xx  +0.1xx
  → 대조군을 이긴 종목 27/34  (방향 정보 있음)
```

**읽는 법 — 딱 두 줄만 보면 된다:**

| 보는 곳 | 통과 기준 | 뜻 |
|---|---|---|
| **`대조군을 이긴 종목`** | 34개 중 **24개 이상** | 방향 정보가 종목을 갈아타도 살아남는다 |
| **합계 `차이`** | **+0.10R 이상** | 우위 크기가 비용에 안 먹힐 만큼 된다 |

이 두 개가 통과하면 **자동매매 게이트 조건 #1 이 진짜로 열린다.**
하나라도 깨지면 SOXL 4개월은 그냥 운이 좋았던 거고, 우린 그걸 안 게 다행인 거다.

---

### 4단계 — 지정가 체결이면 얼마나 달라지나

```powershell
python scripts\ema_multi.py --cost 0.08
```

시장가(0.14%) 대신 지정가(0.08%) 로 잡았을 때다.
**기대값이 얼마나 뛰는지 보면, 체결 로직에 공들일 가치가 있는지 바로 판단된다.**

---

### 5단계 (선택) — 크립토 장기 이력

```powershell
python scripts\fetch_vision.py --symbols crypto --since 2022-01
python scripts\ema_multi.py
```

- ⏱ **20~40분**
- 💾 **약 1.2GB** — 디스크 여유 확인하고 시작
- 2022년부터면 하락장·상승장·횡보장이 다 들어 있다

> 용량이 부담되면 `--symbols BTCUSDT --since 2023-01` 로 하나만 먼저.

## 4. 만약 오류가 나면

| 증상 | 원인 | 해결 |
|---|---|---|
| `python: 명령을 찾을 수 없습니다` | 파이썬 경로 문제 | `py scripts\fetch_vision.py --list` 로 `py` 사용 |
| `❌ 다운로드 실패` 가 계속 | 방화벽/네트워크 | 브라우저로 https://data.binance.vision 열리는지 확인 |
| `No such file: dataset/vision` | 2단계를 안 돌림 | 2단계 먼저 |
| 디스크 가득 참 | 캐시 누적 | `dataset\.vision_cache` 폴더 통째로 지워도 된다 (CSV 는 남는다) |

에러 메시지는 **전체를 그대로** 복사해서 보내줘. 🔑 **API 키는 절대 보내지 마.**
이 스크립트는 공개 데이터만 받아서 키가 아예 필요 없다.
