# Trading Helper — 제품 기획서 (v0.3 · 신호 카드 제외)

작성일: 2026-08-29 · **v0.3 갱신 2026-09-08 (Phase 4 판정 반영)**

> **v0.3 에서 바뀐 것:** Phase 4 백테스트에서 셋업에 방향성 우위가 없다는 것이
> 확인됐다 (`08-전략-검증-결과.md`). 그래서 **신호 카드를 뺀다.** 대신 원래부터
> 검증이 필요 없던 부분 — 청산 회피, 손절 누락 경고, 세션 게이트 — 을 화면의
> 중심으로 올린다. 게이트는 역검정에서 값을 하는 것으로 확인됐다 (−0.285R 차이).
>
> **이건 축소가 아니라 초점 이동이다.** 원래 이 앱의 우선순위가
> `청산 회피 > 진입 금지 구간 > 시나리오 > AI 브리핑` 이었고, 위 두 개가 남았다.

## 1. 무엇을 만드는가

바이낸스 USDⓈ-M **주식 perp(SOXL/USDT 등)를 10배 레버리지로 데이 트레이딩할 때 옆에 띄워두는 실시간 보조 대시보드.**

혼자 쓰는 도구다. 회원가입, 커뮤니티, 마케팅 화면은 없다. 화면 하나에 필요한 것이 다 있어야 한다.

## 2. 사용자의 실제 매매 조건 (설계의 전제)

| 항목 | 값 |
|---|---|
| 거래소 / 상품 | 바이낸스 USDⓈ-M 주식 perp (SOXLUSDT 중심) |
| 레버리지 | 10배 |
| 보유 시간 | 수 분 ~ 수 시간 |
| 목표 수익 | 본주 기준 1~2% (= 포지션 10~20%) |
| 주 분석 타임프레임 | 1분 / 5분 (15분은 맥락용) |
| 사용 시간대 | 한국 시간 저녁~새벽 (미국 프리장·본장) |

## 3. ⚠️ 이 상품의 구조적 위험 — 앱의 존재 이유

**SOXL은 반도체 지수(SOXX)의 3배 ETF다. 여기에 10배 레버리지를 얹으면 SOXX 대비 실효 레버리지가 30배다.**

```
SOXX  -1%  →  SOXL  -3%  →  10x 포지션  -30%
SOXX  -3.2% → SOXL  -9.5% →  청산 (격리마진 10x, 유지증거금 0.5% 가정)
```

반도체 지수가 하루에 3% 움직이는 건 드문 일이 아니다. NVDA 실적, CPI 발표, 관세 뉴스 하나면 나온다. **즉 이 매매는 "언젠가 반드시 오는" 청산 이벤트를 피하는 게임이고, 앱의 1순위 임무는 수익 신호가 아니라 그 순간을 미리 알려주는 것이다.**

그래서 이 앱의 기능 우선순위는 이렇다:

1. **청산 회피** — 청산가까지 거리, 임박 이벤트, 변동성 폭발 경고
2. **진입 금지 구간 통보** — 기술적 분석이 무력한 시간대 (5절)
3. 진입 시나리오 제시 — 방향, 진입, 손절, 익절
4. AI 종합 브리핑 — 두 모델의 시나리오 대조 + 이벤트 해석

## 4. 핵심 화면 — 단일 대시보드

실시간 대시보드 하나로 간다 (푸시 알림은 v2).

│                              │  ■ 포지션 · 청산까지 얼마나  │

│   + VWAP(세션앵커)            │    미실현 +8.2%             │
│   + VWMA 9/21/50             │    청산가 209.8 (−7.1%)     │
│   + 손절 주문 라인 ★          │    ↳ **SOXX 기준 −2.4%** 🟡 │
│   + 이벤트 마커               │    손절 229.6 (−0.6%) ✓     │
│   + 차단 구간 음영 ★          │    다음 펀딩 00:00 · +0.011%│

│ ■ 리스크 게이지               │  ■ 지금 매매하면 안 되는 이유│
│   ATR(1m) 0.28% · 정상        │    · 개장 직후 15분         │
│   호가 스프레드 0.04% · 정상   │    · CPI 발표 32분 전       │
│   본주 괴리 +0.12% · 정상     │    · 거래량 평소의 31%      │
│   오늘 손익 −1.2R (한도 −3R)  │                             │
└──────────────────────────────┴─────────────────────────────┘

★ 는 v0.3 에서 새로 올라온 것.

**"지금 매매하면 안 되는 이유" 패널이 예전 신호 카드 자리를 대신한다.** 이 앱의
주된 출력은 원래부터 진입 권유가 아니라 판단 근거였다 (7절 원칙). 신호가 빠져도
그 자리는 비지 않는다.

**신호 카드를 다시 넣는 조건**은 `04` 문서의 Phase 4 통과 기준 그대로다 —
out-of-sample 기대값 ≥ +0.20R, 표본 ≥ 300. 그전에는 어떤 형태로도 방향을
권하지 않는다.

## 5. 시간대 인식 — 사용자 요청의 핵심

미국 시장은 하루가 4개의 다른 시장으로 쪼개진다. 그리고 이 perp은 **미국 장이 닫혀도 24시간 거래된다.**

| 레짐 | 미국 동부시각 | 한국시각(서머타임) | 앱의 태도 |
|---|---|---|---|
| 🟡 프리장 | 04:00–09:30 | 17:00–22:30 | 신호 발행하되 신뢰도 감점 |
| 🟢 본장 | 09:30–16:00 | 22:30–05:00 | 정상 — 기술적 분석 유효 |
| 🟠 애프터 | 16:00–20:00 | 05:00–09:00 | 실적 발표 반응 구간, 경고 |
| 🔴 언더라잉 클로즈드 | 20:00–04:00 · 주말 · 미국 공휴일 | 09:00–17:00 | **신호 발행 중단** |

🔴 구간에는 본주가 거래되지 않아 perp 가격이 크게 왜곡될 수 있다. 호가가 얇고, 지지·저항이 잘 지켜지지 않으며, 다음 개장 때 갭으로 수렴한다. 10배에서 이 구간에 들어가는 건 도박이다. 앱은 이때 신호를 내지 않는다.

여기에 더해 **레짐 안에서도 기술적 분석이 무력한 시간대**가 있다 — 08:30 ET 지표 발표, 09:30 개장 첫 15분, 14:00 FOMC, 15:45 종가 리밸런싱 등. 전체 목록과 앱의 대응은 `05-세션-이벤트-타임맵`에 정의했다.

## 6. 기능 범위

### v1 (신호 없음)

**검증이 필요 없는 것들만 넣는다.** 아래는 전부 예측이 아니라 사실 조회다.

| 기능 | 왜 검증이 필요 없나 |
|---|---|
| **손절 주문 누락 경고** | 주문 목록을 읽어 STOP 계열·반대방향·reduceOnly 를 확인하는 것뿐 |
| **손절이 청산가보다 먼 경우 경고** | 두 숫자를 비교하는 것뿐. 이 상태는 '손절 없음'보다 위험하다 |
| **손절가가 이미 지나간 경우 경고** | 같음 |
| **청산가 거리 + 기초지수 환산** | "SOXL 9.5% = SOXX 3.2%" 는 나눗셈이다 |
| **일일 −3R 한도 락** | 실현손익 합계. 한 번 닿으면 회복해도 잠긴다 |
| **세션 레짐 + 차단 구간** | 달력과 시계. 게이트 값은 역검정으로 확인됨 (`08` 문서 7절) |
| **이벤트 임박 카운트다운** | FRED·실적 일정 조회 |
| 실시간 1분/5분 캔들 + VWAP + VWMA + 이벤트 마커 | 지표 계산 |
| 호가 스프레드·ATR 이상치·본주 괴리 표시 | 관측값 표시 |

- 바이낸스 **읽기 전용** API 키
- 심볼: SOXLUSDT 중심 + 주요 주식 perp 몇 개

### 빠진 것 (Phase 4 판정)

- ~~신호 카드 (방향/진입/익절/신뢰도)~~ → 우위가 확인되면 복귀
- ~~AI 브리핑~~ → 방향 예측을 전제하므로 함께 보류
- ~~승률 표시~~ → 표시할 승률이 없다

### v2 이후

- 푸시 알림 (서버 감시)
- 매매 일지 + 실제 승률 vs 표시 승률 비교
- 사용자 정의 조건 빌더

### 명시적으로 안 하는 것

- 주문 실행 (읽기 전용 키만 사용)
- 자동매매
- 출금 권한이 붙는 어떤 연동도

## 7. 지켜야 할 원칙

1. **모르면 모른다고 한다.** 🔴 구간, 이벤트 임박 → "판단 보류"를 표시한다. 억지로 신호를 만들지 않는다. **Phase 4 에서 이 원칙을 실제로 적용해 신호 기능 자체를 뺐다.**
2. **숫자를 지어내지 않는다.** 승률·확률은 백테스트나 모델 출력에서만 나온다. LLM은 계산된 숫자를 설명만 하고 새 숫자를 만들지 않는다.
3. **청산 경고가 수익 신호보다 위에 있다.** 화면 배치도 그렇게 한다.
4. **웹과 앱은 같은 답을 낸다.** 계산은 전부 서버에서만.

## 8. 성공 기준

- 지연: 1분봉 마감 → 대시보드 갱신 1초 이내
- 안전: 🔴 구간·이벤트 임박 구간에서 신호가 새어 나가지 않음 (테스트로 고정)
- **경고 정확성: 손절 없이 열린 포지션을 100% 잡아낸다. 거짓 안심을 주는 상태
  (손절이 청산가보다 멀거나 이미 지나간 경우)도 함께 잡는다** — 테스트 68개로 고정
- 유용성: 사용자가 이 앱 없이 매매할 때보다 청산·대손 횟수가 줄어드는 것
